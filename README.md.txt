# Customer Transaction ETL Pipeline (AWS Simulation)

**Tech:** Python, PySpark, SQL, AWS S3 (sim), AWS Lambda (sim), Redshift (sim), ETL, Data Validation

This repo demonstrates an end-to-end data engineering pipeline that ingests customer transaction CSVs,
transforms them using **PySpark**, and simulates cloud orchestration/storage (S3, Lambda, Redshift).
The pipeline is built to handle **large datasets (1M+ rows, 20 columns)** and is fully runnable locally.
